# IEEE 1028

IEEE 1028 describe prácticas para revisiones de software, inspecciones y auditorías.

Puntos relevantes:

- Planificación de la revisión
- Roles y responsabilidades
- Registro de hallazgos
- Seguimiento y cierre

En AuditAI, esta norma se usa para estructurar el proceso de auditoría, la evidencia y la trazabilidad de resultados.
