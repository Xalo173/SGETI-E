# ISO/IEC 25010

La norma ISO/IEC 25010 define el modelo de calidad del producto software.

Características principales:

- Adecuación funcional
- Eficiencia del desempeño
- Compatibilidad
- Usabilidad
- Fiabilidad
- Seguridad
- Mantenibilidad
- Portabilidad

Durante el diseño de evaluación, esta norma ayuda a derivar criterios y métricas observables para un software bajo auditoría.
